# The complete Linux filesystem guide

> 14 paths every Linux user touches — each one explained.

A tour of the directories under `/` on a typical Linux system: what each one
holds, why it exists, and when you'll actually open it.

**PDF:** [linux_filesystem_guide.pdf](linux_filesystem_guide.pdf)
**Instagram:** [@kerem.tech post](https://www.instagram.com/p/DYMTLojjM8n)

## Directories covered

`/etc` · `/var` · `/home` · `/tmp` · `/proc` · `/sys` · `/usr` · `/root` ·
`/opt` · `/dev` · `/boot` · `/bin` · `/lib` · `/mnt`

Aligned with the [Filesystem Hierarchy Standard](https://refspecs.linuxfoundation.org/fhs.shtml).

## Who it's for

Newcomers to Linux, sysadmins onboarding to a new distro, and developers who
want a mental map of where things live before they go hunting with `find`.
